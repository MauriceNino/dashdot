[Easypanel](https://easypanel.io) is a self-hosted Docker deployment platform. It has a one-click Easypanel template for Dash., which deploys the image above with sensible defaults.

[![Deploy on Easypanel](https://easypanel.io/img/deploy-on-easypanel-40.svg)](https://easypanel.io/templates/dashdot)

![dash. running in the Easypanel panel](/img/easypanel-panel.png)

<Callout type="info">
  The Easypanel template runs dash. in container mode (monitoring the
  container's own resources) rather than mounting the host filesystem. If you
  need host-level stats, use the [Docker](/docs/installation/docker)
  installation instead.
</Callout>
